## 每份文档固定包含

1. **这一阶段要解决什么** + 出口条件（做完没做完，用出口条件判定）
2. **核心原理讲解**（用比喻和手算例子，不讲黑话）
3. **逐块讲解**：每个工作块做了什么、为什么这么做、代码在哪
4. **文件清单**：文件 → 作用 → 对应知识点
5. **怎么跑起来验证**：命令 + 期望结果 + 常见报错排查
6. **踩过的坑 / 易错点**
7. **动手练习**（可选）：改一个小参数，看指标怎么变
