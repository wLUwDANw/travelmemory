## 踩到的坑（下次直接绕）

1. **pytest exit code 会被安全钩子置 1**，末尾那行 `[safe-delete]...` 不是失败。
   **以 `--junit-xml` 里的 `failures="0"` 为准**。
2. **`fireEvent.change(input, { target: { files } })` 静默失效**：
   `input.files` 是只读 FileList，没有 setter，赋值不报错也不生效。
   必须用 `Object.defineProperty(input, 'files', { value: [file], configurable: true })`。
3. **jsdom 的 `File` 没有 `.text()`**（浏览器有）。不补会抛 TypeError 被 catch 兜成
   "读不出这个信物"，于是每条用例只能测到"打不开"这条路径。用 `FileReader` 补齐。
4. **`waitFor` 要等"结果出现"，不要等"loading 消失"**：`verifying` 在第一轮 render
   之后才翻 true，"找不到『正在验证』"在异步开始前就成立 → waitFor 立刻通过，
   断言跑在状态更新之前。
5. `getByText` 对**重复出现**的文案会报 multiple elements —— 三条 CheckItem 共用
   同一句失败原因，要用 `getAllByText`。
6. mypy：`session.execute(...).scalars().all()` 是 `Sequence`，声明 `list[Trip]`
   要包一层 `list(...)`。

## 第二班：前端产品化重构（全屏地图 + 抽屉化）

人类实测反馈"交互体验极差"：顶部 Tab 把地图割裂、新建行程无编辑入口、
导入照片无定位反馈。本轮把壳层从"三页签"改成"**全屏地图 + 浮层**"。

### 壳层结构

- `App.tsx` 只做两件事：全屏渲染 `MapPage`，持有跨浮层共享的
  `mapPlaces`（信物地点）与 `trips`（行程列表）。删掉 `app-nav` / `app-main` 三 Tab。
- `MapPage.tsx` = 全屏地图壳：左上品牌条、左下信物工具栏、右缘半圆形抽屉 Tab、
  右下 AI FAB、底部常驻计数。**三个浮层互斥**（同时只开一个）——
  两个抽屉各占 400px 会把地图挤成一条缝，而用户此刻正需要看着地图。
- 初始视野 `[104.195, 35.861]` / `zoom 4`（`lib/mapView.ts`），
  替掉旧的 `[105,35]`+zoom11 —— 后者一进页面先看到大西北荒原。

### 新增/改写的文件

- `components/ui/sheet.tsx`（Radix Dialog 侧边变体）、`scroll-area.tsx`、
  `textarea.tsx`；装 `@radix-ui/react-scroll-area`
- `AgentPage/ChatPanel.tsx` + `useChatSession.ts`（流式逻辑从页面里抽出来）
  + `chatHistory.ts`（localStorage 会话历史，storage 可注入）
  - 删 `AgentPage.tsx`、`EvidenceList.tsx`（ChatPanel 内联重写了证据列表）
- `MapPage/TripDrawer.tsx`（原 `MapActionPanel` 改造）：新建旅程 / 导入照片 /
  图层开关 / **行程列表**（含未定位计数）
- `MapPage/ShareDialog.tsx`：整页 SharePage 装进 Dialog，
  `section`  prop 让「生成信物」「验证信物」各自滚到对应锚点
- `lib/mapView.ts`：默认视野 + `parseEvidenceRef` / `findPointForEvidence` / `dedupePoints`
- 删 `PlaceholderActionDialog.tsx`、`MapActionPanel.tsx`；`styles.css` 删
  `.app-nav` 等死规则，`.share-page` 改成对话框内的纵向节奏

### 修掉的坑

1. **`fitBounds` 竞态**：父组件 `await 刷新行程()` 返回时 React 还没重渲染，
   此时调 `ref.fitAll()` 读到的是**上一批**覆盖物 → 飞向旧位置且不报错。
   改用 `fitSignal` 计数器走同一次 commit（effect 先重画覆盖物再 fit）。
2. **`fireEvent.change` 找不到 input**：文件输入框搬进 Sheet 后，
   Radix 关闭时**不挂载内容**，测试要先点开抽屉。已加 `openDrawer()` 辅助。
3. **`dayOf` 只查形状**：`2026-13-99` 匹配 `\d{4}-\d{2}-\d{2}` 但不是真日期。
   改成过 `new Date` + **反向比对**（防 `2026-02-31` 被静默滚成 3 月 3 日）。
4. **`CaptionJob` 测试隔离缺陷**（后端，顺带修）：候选选取原本全库全用户，
   `report.succeeded == 6` 会随库里别人的 pending 照片浮动 —— 演示库一有
   pending 就红，且**不报错、只是数字不对**。给 `CaptionJob` 加可选
   `user_id` 参数（不传 = 全库，生产行为不变），测试传自己的 user_id。

### 重命名（补齐"允许重命名"）

后端原本只有 GET/POST。新增 `PATCH /api/v1/trips/{id}` +
`services/trip_service.py::rename_user_trip()`。
**关键取舍**：改名即把 `source` 提升为 `manual`，否则下次导入触发的
`rebuild_user_trips()` 会按 `source == cluster` 把这行连标题一起删掉。
代价是这趟行程不再自动更新，收益是用户敲的字不丢。
